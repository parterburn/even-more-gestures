# Even More Gestures 0.2.25

- Three-finger click and tap now begin enabled with middle-click selected unless you have already changed them.
- Made four-finger sidebar swipes easier to recognize and flag macOS Spaces swipes when they conflict.
- Chrome’s right-sidebar default now uses `⌃G` to show or hide Gemini.
- Added a DMG installer with an Applications shortcut for drag-and-drop installation.
